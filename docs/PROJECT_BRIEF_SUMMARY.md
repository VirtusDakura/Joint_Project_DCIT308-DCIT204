# DCIT 204/308 Joint Semester Project — Key Constraints
> **Department of Computer Science — University of Ghana**

## 🎯 Rules & Constraints (from Project Brief)
1. **Core Language**: Java 17 (Maven build system).
2. **Database**: PostgreSQL / SQLite integration via JDBC. The database must be part of the running system, not just storage.
3. **No Built-in Collections**: `java.util.ArrayList`, `HashMap`, `PriorityQueue`, `Stack`, `ArrayDeque`, `TreeMap` and similar are **NOT allowed** for core processing. All data structures must be custom-built from scratch (Section 6).
4. **Built-in Java Allowed For**: File I/O, JDBC, printing, plotting export, and JUnit 5 test scaffolding.
5. **Console Menu or Simple GUI**: The program must allow an examiner to run demonstrations without editing source code.
6. **Minimum Dataset Sizes**:
   - **Locations**: 50 records
   - **Roads / Edges**: 100 records
   - **Service Requests**: 300 records
   - **Resources**: 30 records
   - **Algorithm Benchmark Runs**: 30 records
7. **Ghana Localisation**: All data must use real Ghanaian place names, routes, and constraints. A short evidence note must explain how the dataset was constructed from local knowledge.
8. **Index Number Parameters**: At least 3 algorithm parameters derived from team member Student Index Numbers.
9. **Trace Tables**: At least 6 required (binary search, insertion sort, merge sort/quicksort, Dijkstra, Kruskal/Prim, DP).
10. **Proof Sketches**: At least 3 (loop invariant for search/sort, induction/recursion proof, greedy/DP correctness idea).
11. **Counterexamples**: At least 2 (one greedy failure, one invalid precondition like unsorted binary search).
12. **Unit Tests**: At least 40 across data structures and algorithms covering normal, boundary, and invalid input.
13. **Performance Experiments**: At least 6 experiments, 5 input sizes, 3 repeated runs each. Export to CSV, plot line graphs.
14. **Oral Defense**: Every member defends **1 data structure** and **1 algorithm** during the oral presentation.
15. **Technical Report**: 12-section PDF/DOCX with screenshots, trace tables, and graphs.
16. **Demonstration Video**: 5–8 minutes showing database load, core algorithms, tests, and graphs.
